Privacy and clearing data

Device storage is not encrypted. An exported password-protected backup uses AES-256-GCM with PBKDF2-SHA256 (250,000 iterations). Someone using this browser can read remembered data. A strong backup password is essential.

Clearing contact details and clearing organizer records are separate actions. Neither deletes files already downloaded.
