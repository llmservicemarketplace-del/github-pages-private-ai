# PAi Claims partner outreach kit

## Campaign objective

Earn appropriate resource-directory links and newsletter mentions from organizations that already help disaster survivors and homeowners. The ask is for a review of the public resource, not an endorsement.

## Primary link

https://yprivateai.com/share-pai-claims.html

## Short directory description

PAi Claims is private-first Windows software that helps homeowners organize property-damage photographs, documents, measurements, estimates and correspondence. Download and setup are free; the introductory first claim is $20. Free disaster-recovery guides and assistance links are also available. PAi Claims is documentation software, not an insurer, public adjuster or law firm.
