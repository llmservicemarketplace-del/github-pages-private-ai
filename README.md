# Private AI Setup Portal (GitHub Pages Version)

This is a web-based redemption and setup portal for Private AI, designed to be hosted on GitHub Pages. It handles post-purchase automation for eBay sales.

## Features

- Simple code entry landing page
- Code validation via backend endpoint
- Automatic flow to model selection after valid code
- Model selection from catalog
- License presentation for gated models
- Simulated download progress
- Platform-specific download instructions for the actual Private AI app

## How It Works

1. Customer receives eBay item with a scratch-off card containing a code
2. Customer visits your GitHub Pages site (e.g., `https://yourusername.github.io/private-ai-setup/`)
3. Customer enters the code and clicks Continue
4. Site validates code with your backend (`codes.py serve` endpoint)
5. After successful validation, customer selects an AI model from available options
6. If model requires license acceptance, terms are shown
7. Simulated download progress is displayed
8. Customer is directed to download the Private AI app for their platform
9. During actual app setup, the selected model is configured

## Backend Requirements

To make this work, you need to host the following backend services:

### 1. Code Validation Endpoint
Run `codes.py serve` on a domain you control (e.g., `https://api.yourdomain.com`):

```bash
./codes.py serve --port 8787
```

**You MUST put TLS in front of this** before it goes live!  
The endpoint should be available at: `https://api.yourdomain.com/v1/claim`

### 2. Catalog Hosting
Host your `catalog-v1.json` file (generated by `./catalog.py publish`) on a CDN or static hosting:
- Example: `https://cdn.yourdomain.com/catalog-v1.json`

### 3. Private AI Distribution
You'll need to distribute the Private AI desktop applications (Windows/macOS/Android) through your own channels.
The GitHub Pages site provides download links pointing to your distribution URLs.

## Setup Instructions

### 1. Configure the Frontend
Edit `setup.js` and update these constants:
```javascript
const BACKEND_URL = 'https://api.yourdomain.com'; // Where codes.py serve is hosted
const CATALOG_URL = 'https://cdn.yourdomain.com/catalog-v1.json'; // Where catalog is hosted
```

### 2. Deploy to GitHub Pages
1. Push all files to the `index.html`, `setup.js`, `setup.html`, `setup.css`, and `app.css` files to a GitHub repository
2. Enable GitHub Pages in the repository settings
3. The site will be available at `https://yourusername.github.io/repository-name/`

### 3. Test the Flow
1. Generate a test code with: `./codes.py mint 1 --batch test`
2. Visit your GitHub Pages site
3. Enter the code
4. Select a model
5. Complete the flow

## File Structure

- `index.html` - Landing page with code entry
- `setup.html` - Wizard steps (model selection, license, download, done)
- `setup.js` - Shared JavaScript for both pages
- `setup.css` - Styling for the wizard
- `app.css` - CSS variables used by setup.css
- `README.md` - This file
- `.nojekyll` - Prevents Jekyll processing on GitHub Pages

## Security Notes

- **Never expose your private keys or sensitive data in the frontend**
- The codes validation endpoint (`codes.py serve`) should be rate-limited and protected
- Consider adding domain validation to prevent abuse
- All model downloading happens in the Private AI desktop app, not in the browser

## Customization

To change the number of models displayed or their selection logic, modify the `loadPicks()` function in `setup.js`.

The current implementation shows all enabled models from the catalog that are compatible with the detected platform.

## Complete Customer Flow

1. **eBay purchase** → customer gets card with code (e.g., `PAI-AB12-CD34`)
2. **Customer visits**: `https://yourusername.github.io/your-repo/`
3. **Enters code** → clicks Continue
4. **Site validates** with your backend (`codes.py serve`)
5. **After validation**: automatically shows 4 model options from your catalog
6. **Selects model** → sees license (if needed) → accepts
7. **Views download progress** → then gets:
   - Direct download link to your Private AI app (for their OS)
   - Instructions that during app setup, it auto-configures with selected model
8. **Customer installs app** → works completely offline ("nothing leaves computer")
