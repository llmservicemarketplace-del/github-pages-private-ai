Set up PAi with your activation code

PAi installs from the Microsoft Store. On first run it asks for your activation code, checks your computer, and offers only the AI options your hardware can actually run.

Get PAi from the Microsoft Store

Getting started

  1. Install PAi from the Microsoft Store using the button above.
  2. Open PAi from the Start menu.
  3. Enter the activation code from your purchase email.
  4. Allow PAi to check your computer’s memory, disk space and graphics.
  5. Choose one of the AI engines PAi offers for your hardware (DeepSeek, Qwen, Llama or Gemma).
  6. PAi downloads and configures it. This takes a while the first time. The download resumes if interrupted.

Do not download AI model files manually. PAi handles model downloads, hardware compatibility, installation and configuration for you.

After setup you can disconnect the internet. The software continues to work offline.

System requirements

Windows 10 or 11, 64-bit. 8 GB memory minimum (16 GB recommended). About 10 GB free disk space. No Python, Docker or developer tools required.
