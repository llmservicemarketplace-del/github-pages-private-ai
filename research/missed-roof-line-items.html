Which roof items do insurance estimates often leave out?

A roof replacement is more than shingles. When an estimate lists only "remove and replace shingles" by the square, several required parts of the job may be missing. Each one below is a real cost that a roofer will charge for.

The short answer. Compare the estimate with a roofer's itemized bid and the local building code. Ask, in writing, for each missing item that the job actually requires.

Partial repair or full replacement?

If the estimate repairs only some slopes and the new shingles won't match the old ones, the policy language and state rules on matching decide what's owed. See matching and, in Florida, Florida's roof matching rule.

How to ask for missing items

  1. Get an itemized roofer's bid with quantities.
  2. Mark each item missing from the carrier's estimate.
  3. Cite the code section or manufacturer instruction where an item is required.
  4. Send it in writing with photos and ask for a revised estimate or a re-inspection.

Quick answers

Does insurance pay for drip edge?

If drip edge is part of a covered roof replacement and is required by code or needed to complete the work, it is commonly included. If code requires it and it wasn't there before, ordinance or law coverage may apply.

Why did my estimate only pay for some roof slopes?

The adjuster found damage only on those slopes. You can dispute that with photos and a roofer's inspection, and raise matching if repaired slopes won't match.

Is roof decking covered?

Damaged decking from a covered loss is usually part of the repair. It is often found only during tear-off, so report it immediately with photos before it's covered.
